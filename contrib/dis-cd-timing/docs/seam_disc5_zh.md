# 第 5 张盘（三次轨距测试版 + 二次参数）核对，与 33.4 mm 处的刻录接缝

## 结论

> **更新（2026-11-05）：** 新型号的探测盘（同一台光驱、同样 4×）在扇区 65 500 两侧测得 g = −0.01 ± 0.04 mm，也就是没有接缝。所以这道接缝不是光驱的固定行为，只是第 5 张盘那一次刻录出现的。下文的 `prewarp.py --link` 预补偿**不要默认使用**（刻录前无法知道这一次会不会有）。数据：`out\newmodel_seam\localsteps_60067.csv`、`out\newmodel_fit_link65536.json`。

- **参数和刻进去的数据都是对的。**
  - 读回的数据确认刻录用的就是二次参数：实线辐条在数据里的角度误差不超过 0.08°（约 0.04 mm）。
  - 这张盘自己的计时拟合与整盒一致。按它预测，实线两半错开 B ≈ −0.08 mm，内端偏 −0.04 mm，中段弯曲 ≤ 0.07 mm，也就是"直的"。这与你看到的"整体是直线"相符。
- **30–35 mm 圈之间的错位是刻录时留下的"接缝"，不是参数问题。**
  - 光驱刻到扇区约 65 500（r ≈ 33.45 mm，盘上约 14:33）时停了一下，再接着刻（无损续刻），接上的位置晚了约 0.2 mm。
  - 从那里往外的全部图案因此沿轨道整体前移约 0.2 mm，所以每条实线在同一半径处出现同样大小的错位，前后两段都是直的。
  - 改那 5 个参数修不掉它：参数管的是整条螺旋的形状，接缝是刻录过程中的一次跳变。

## 证据

| 方法 | 结果 |
|---|---|
| 照片（`docs\jog_photo_annotated.png`） | 错位在 30 mm 与 35 mm 圈之间，按两圈的位置内插 r ≈ 33.4 mm；外侧整段辐条平移约 0.43 个线宽（线宽 0.45 mm → 约 0.19 mm），两侧都是直的 |
| 读回数据（每 2 mm 一组采样） | 数据本身没有错位：29.5、31.5、33.5、35.5 mm 处实线都在 0 ± 0.08° |
| 读盘错误（28–38 mm 全部扇区） | 没有 C2 错误，子码 Q 没有异常聚集，所以是"干净"的接缝，只有计时和肉眼能看出来 |
| 计时（`results\disc5_jog`、`disc5_jog2`，参考扇区在 32.8 mm） | r ≤ 33.31 mm 的扇区与平滑螺旋相符；r ≥ 33.44 mm 的扇区整体前移。台阶 **g = +0.20 ± 0.03 mm**（考虑逐扇区散布后 ±0.06 mm），位置在扇区 64 600–65 640（r 33.32–33.44 mm）之间，加上台阶后 chi2 从 33 降到 4 |
| 第 1、3 张盘的旧计时数据 | 同一区间（32–34 mm，测点每 2 mm 一个）也有同号、同大小的台阶：+0.25 ± 0.08、+0.17 ± 0.10 mm。三张盘合在一起 0.21 ± 0.03 mm，彼此一致 |
| 全部数据联合拟合（`calibrate_pitch.py --link`，梯子 + 4 次 localsteps，2026-11-05） | 台阶在扇区 65 536 处：g = +0.162 ± 0.048 mm；在 65 600 处：g = +0.196 ± 0.047 mm，chi2 119 对 130，后者更好。所以台阶多半在 0x10000 之后几十个扇区，不是正好在 0x10000 |

- 刻录速度：程序默认"自动（最低速率）"，在这台光驱上是 4×（光驱报告的 CD-R 写速为 4/8/12/16/24×，`results\writespeeds`）。
- 软件给刻录接口留了 64 MiB 的数据缓冲（4× 下约 90 秒），不会是软件供数不及；更可能是光驱（或 Windows 的 IMAPI 刻录接口）自己的行为。
- 扇区 65 536 = 0x10000 就在台阶附近，但联合拟合更支持 65 600 左右，所以"正好在 0x10000"没有得到支持。40.17 mm（0x20000）处没有同样的台阶。

## 修复：刻录前对设计图做"接缝预补偿"

参数不用改。刻录前用 `analysis\prewarp.py` 把设计图中 r > 33.45 mm 的部分预先往回转 g/r，光驱接缝时往前一跳，两者正好抵消：

```powershell
# 测试版（带轨距系数，已经没有 S 形弯）：只补接缝
python -I analysis\prewarp.py 设计图.png 设计图_接缝补偿.png --r1 <工程外半径> --coeffs 0 --const 0 --link 33.42,0.21
# 旧版 v1.3.6（恒定轨距）：同时消 S 形弯和接缝
python -I analysis\prewarp.py 设计图.png 设计图_接缝补偿.png --link 33.42,0.21
```

- `--r1`、`--input-r1` 的含义见 README 的 prewarp 一节。生成的图按 100 %、偏移 0、旋转 0 导入。
- 预计错位降到约 0.05 mm 以下。大小的误差约 ±0.04 mm；位置差 0.1 mm 只影响很短的一小段，看不出来。
- **前提：接缝每次都出现在同一位置。** 下一张盘（新型号的探测盘）会顺便测一次。若位置或大小变了，就不要用这个补偿。
- 换新型号时，接缝半径要按新参数重新换算（扇区约 65 500 处的半径）。

## 工具和数据

- `analysis\step_scan.py`：在每张盘的计时数据里找单个台阶（平滑螺旋 + 一个台阶，扫描台阶位置），并给出三张盘同一位置的联合结果。
- `analysis\jog_estimate.py`：在已知半径处估计台阶的大小。
- `analysis\link_locate.py`：用同一参考扇区的几次测量，定位台阶落在哪两个测点之间。
- `results\disc5_link`、`disc5_link2`、`disc5_jog`、`disc5_jog2`：localsteps 测量和 28–38 mm 的 C2/子码扫描；`results\writespeeds`：光驱报告的写速。
- `src_extra\`：这次用到的只读阶段 `localsteps`、`linkscan`、`writespeeds` 的源码，还没有并入 `src\`。
